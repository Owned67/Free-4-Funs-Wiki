## Présentation

Ce plugin vous permet de rentabiliser vos serveurs, lors de la transition du joueur dans la fenêtre du Motd, une publicité aléatoire s'affichera (vidéo avec et/ou sans son, bannière) (compatible L4D et L4D2).

## Requis

```text
* Il vous faudra créer un compte sur [http://motdgd.com/?r=47 ce site]
```

Pour me remercier du travail effectué sur le wiki, vous pouvez vous enregistrer à partir du lien, il s'agit d'un parrainage (je gagnerais 10% sur ce que vous gagnerez par jour).

## Téléchargement

[MOTDgd Advertisements](https://tutocss.pages-perso.free.fr/wiki/motdg_ads.zip)

## Installatio

- 1. Téléchargez l'archive
- 2. Décompressez l'archive sur votre ordinateur (avec un logiciel de décompression...)

- 3. Envoyez le contenu des dossiers **addons** et **cfg** dans le dossier **/games/l4d2/left4dead2** de votre serveur FTP

- 4. Redémarrez votre serveur

## Configuration

Après avoir redémarré le serveur, vous devrez éditer le fichier **plugin.motdgd_adverts.cfg** du répertoire **/../../left4dead2/cfg/sourcemod**:

```text
// This file was auto-generated by SourceMod (v1.5.0-dev+3839)
// ConVars for plugin "motdgd_adverts.smx"

// The MOTD URL found on Your Portal Dashboard at motdgd.com
// -
// Default: ""
sm_motdgd_url "http://motdgd.com/motd/?user=47"

// Whether ADMIN_RESERVATION players are immune to MOTDgd advertisements
// -
// Default: "1"
sm_motdgd_immunity "0"

// Whether eligible players are shown MOTDgd every X minutes during the game, 0 is disabled, minimum 20 minutes
// - 
// Default: "20"
sm_motdgd_review_minutes "20"

// Whether eligible players are shown MOTDgd after [review_minutes] have passed, 0 is on death, 1 is on round start (default)
// -
// Default: "1"
sm_motdgd_review_mode "1"
```

- **sm_motdgd_forced** ![icon11](/images-wiki/icon11.gif) Ne pas modifier !

- **sm_motdgd_immunity** ![icon11](/images-wiki/icon11.gif) Permet d'immuniser les administrateurs selon le flag (ceci pourra être modifié dans le fichier .sp)

- **sm_motdgd_review_minutes** ![icon11](/images-wiki/icon11.gif) Temps d'attente pour revoir une vidéo publicitaire.

- **sm_motdgd_url** ![icon11](/images-wiki/icon11.gif) Lien permettant au plugin de vous identifier (47 est mon ID donc pensez bien à mettre le votre !).

- 1. Tapez la commande suivante dans la console de votre serveur (par RCON ou via le logiciel  [HLSW](/pages-wiki/hlsw)) :<br />

- [HLSW](/pages-wiki/hlsw) ![icon11](/images-wiki/icon11.gif) **sm plugins list**

Cette commande sert à afficher la liste des plugins SourceMod installés sur votre serveur :
