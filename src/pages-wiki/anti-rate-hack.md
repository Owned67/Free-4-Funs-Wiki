## Présentation

Anti Rate Hack Permet de kicker les joueurs qui s'amuse à modifier leur rates trop souvent.

## Téléchargement

[Anti Rate Hack](https://tutocss.pages-perso.free.fr/wiki/Anti_Rate_Hack.zip)

## Installation / Configuration

- 1. Téléchargez l'archive
- 2. Décompressez l'archive sur votre ordinateur (avec un logiciel de décompression...)

- 3. Envoyez le contenu du dossier addons dans le dossier **/games/l4d2/left4dead2/left4dead2** de votre serveur FTP

- 4. Redémarrez le serveur

## Comment configurer le plugin ?

![warning](/images-wiki/warning.png) Le serveur devra être redémarré pour générer le fichier de configuration ci-dessous !

Avec un éditeur de texte, ouvrez le fichier **plugin.antiratehack.cfg** situé dans le répertoire **/games/l4d2/left4dead2/cfg/sourcemod** :

```text
// This file was auto-generated by SourceMod (v1.4.4)
// ConVars for plugin "antiratehack.smx"

// Only people with this flag will see the notice about cheating (empty - everyone)
// Seuls les personnes ayant le flag verront la notice (si aucun flag - tout le monde verra la notice)
// -
// Default: "z"
sm_antiratehack_notifyflag ""

// How many rate changes should be done to show the info on chat and kick the player
// Combien de fois le joueur est autorise a changer ses rates avant d'etre kicke
// -
// Default: "15"
sm_antiratehack_notifythreshold "15"

// Notification types: 0 - off 1 - server console, 2 - chat, 4 - player console (can be added up)
// Methode d'affichage : 0 - desactive 1 - console du serveur, 2 - chat, 4 - console du joueur
// -
// Default: "3"
sm_antiratehack_notifytype "2"
```

Pour modifier la traduction française de ce plugin, il vous faudra éditer le fichier **antiratehack.phrases.txt** du dossier **/games/l4d2/left4dead2/addons/sourcemod/translations/fr/**

Sauvegarder les modifications puis redémarrer votre serveur.

## Vérification de l'installation

- 1. Tapez la commande suivante dans la console de votre serveur (par RCON ou via le logiciel [[Hlsw|HLSW]) :<br />

- Rcon ![icon11](/images-wiki/icon11.gif) **rcon_password votre_passe_rcon** ![icon11](/images-wiki/icon11.gif) **rcon sm plugins list**

- [[Hlsw|HLSW] ![icon11](/images-wiki/icon11.gif) **sm plugins list**

Cette commande sert à afficher la liste des plugins SourceMod installés sur votre serveur :

