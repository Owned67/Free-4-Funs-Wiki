## Présentation

Very Basic High Ping Kicker Permet de kicker les joueurs ayant un ping élevé.

## Téléchargement

[Very Basic High Ping Kicker](https://tutocss.pages-perso.free.fr/wiki/VHBK.zip)

## Installation / Configuration

- 1. Téléchargez l'archive
- 2. Décompressez l'archive sur votre ordinateur (avec un logiciel de décompression...)

- 3. Envoyez le contenu des dossiers **addons** et **cfg** dans le dossier **/games/l4d2/left4dead2** de votre serveur FTP

- 4. Redémarrez votre serveur

## Comment configurer le plugin ?

Avec un éditeur de texte, ouvrez le fichier **vbping.cfg** situé dans le répertoire **/games/l4d2/left4dead2/cfg/sourcemod** :

```text
// This file was auto-generated by SourceMod (v1.5.2)
// ConVars for plugin "vbping.smx"

// Period in seconds when rate is checked
// -
// Default: "10.0"
// Minimum: "1.000000"
sm_vbping_checkrate "15.0"

// SourceMod admin flag used to grant immunity to all ping checking/kicking
// -
// Default: "a"
sm_vbping_immunityflag "a"

// Kick message sent to kicked client
// -
// Default: "You have been kicked due to excessive ping"
sm_vbping_kickmsg "You have been kicked due to excessive ping"

// Public kick message. {NAME} converts to the player's name.
// -
// Default: "{NAME} was been kicked due to excessive ping"
sm_vbping_kickmsgpublic "{NAME} was been kicked due to excessive ping"

// Log warning and kick actions. 0 = Disabled, 1 = Enabled
// -
// Default: "0"
// Minimum: "0.000000"
// Maximum: "1.000000"
sm_vbping_logactions "1"

// Maximum player ping
// -
// Default: "150"
// Minimum: "1.000000"
sm_vbping_maxping "150"

// Number of warnings before kick
// -
// Default: "2"
// Minimum: "1.000000"
sm_vbping_maxwarnings "2"

// Minimum number of players before kicking
// -
// Default: "4"
sm_vbping_minplayers "2"

// Minimum playtime before ping check begins
// -
// Default: "90"
sm_vbping_mintime "35"

// Enable/disable public kick message. 0 = Disabled, 1 = Enabled
// -
// Default: "0"
// Minimum: "0.000000"
// Maximum: "1.000000"
sm_vbping_showpublickick "1"

// Enable/disable warning messages. 0 = Disabled, 1 = Enabled
// -
// Default: "1"
// Minimum: "0.000000"
// Maximum: "1.000000"
sm_vbping_showwarnings "1"

// Warning message sent to high ping client. {WARN} and {MAXWARN} converts to the warning count and max warnings respectively.
// -
// Default: "You will be kicked for excessive ping. You have {WARN} out of {MAXWARN} warnings."
sm_vbping_warningmsg "You will be kicked for excessive ping. You have {WARN} out of {MAXWARN} warnings."
```

**sm_vbping_checkrate** ![icon11](/images-wiki/icon11.gif) Vérification des rates (en secondes).

**sm_vbping_immunityflag** ![icon11](/images-wiki/icon11.gif) Permet d'immuniser les admins en définissant le flag.

**sm_vbping_kickmsg** ![icon11](/images-wiki/icon11.gif) Message affiché lors du kick.

**sm_vbping_kickmsgpublic** ![icon11](/images-wiki/icon11.gif) Message affiché aux autres joueurs (si sm_vbping_showpublickick est définis à 1).

**sm_vbping_logactions** ![icon11](/images-wiki/icon11.gif) Enregistre dans un fichier **vping.log** toutes les actions; A 0 = désactivé"

**sm_vbping_maxping** ![icon11](/images-wiki/icon11.gif) Temps de latence maximum autorisé.<br />

**sm_vbping_minplayers** ![icon11](/images-wiki/icon11.gif) Nombre de joueurs présent sur le serveur pour pouvoir kicker.<br />

**sm_vbping_mintime** ![icon11](/images-wiki/icon11.gif) Combien de temps doit attendre le plugin avant de vérifier le joueur en jeu<br />

**sm_vbping_showpublickick** ![icon11](/images-wiki/icon11.gif) 0 Aucun message sera envoyé aux autres joueurs. 1 Un message sera envoyé dans le chat. (Voir **sm_vbping_kickmsgpublic**)<br />

**sm_vbping_warningmsg** ![icon11](/images-wiki/icon11.gif) Message d'avertissement affiché au joueur ayant un trop gros ping avec le nombre maximum d'avertissements pouvant être donné avant le kick.<br />

Modifiez puis sauvegarder les modifications et redémarrer votre serveur.

## Vérification de l'installation

- 1. Tapez la commande suivante dans la console de votre serveur (par RCON ou via le logiciel [HLSW](/pages-wiki/hlsw)) :<br />

- Rcon ![icon11](/images-wiki/icon11.gif) **rcon_password votre_passe_rcon** ![icon11](/images-wiki/icon11.gif) **rcon sm plugins list**

- [HLSW](/pages-wiki/hlsw) ![icon11](/images-wiki/icon11.gif) **sm plugins list**

Cette commande sert à afficher la liste des plugins SourceMod installés sur votre serveur :
