## Description

GCFScape est un logiciel qui permet d'extraire les formats : .bsp, .gcf, .ncf, .pak, .vpk, .wad et .xzp

- **.bsp** ![icon11](/images-wiki/icon11.gif) les maps dans les différents jeux,

- **.gcf** ![icon11](/images-wiki/icon11.gif) les fichiers cache de Steam,

- **.vpk** ![icon11](/images-wiki/icon11.gif) les fichiers cache du jeu Left 4 Dead et Left 4 Dead 2,

- **.ncf** ![icon11](/images-wiki/icon11.gif) les fichiers de base du jeu / des jeux installés

- **.pak** ![icon11](/images-wiki/icon11.gif) Half-Life 1

- **.wad** ![icon11](/images-wiki/icon11.gif) les textures Half-Life 1.

- **.xzp** ![icon11](/images-wiki/icon11.gif) Aucune information...

Il est indépendant de Steam.

Cette utilitaire peut vous permette de personnaliser l'interface graphique de votre jeux préféré.

Cela s'appel un GUI (Graphic user Interface) cependant à chaque nouvelle mise à jour client de Steam, il vous faudra regarder les modifications dans fichiers concernés.

## Prérequis

- .NET Framework 2.0, 3.0 ou 3.5 et Visual C++ 2008 SP1.

## Téléchargement

- [GCFScape 1.8.5](https://tutocss.pages-perso.free.fr/wiki/gcfscape185.exe)

## Installation

Rien de bien compliquer, éventuellement pensez à associer toutes les extensions au logiciel.

Ouvrez le logiciel ![icon11](/images-wiki/icon11.gif) Options ![icon11](/images-wiki/icon11.gif) Associations :
![f4f gcfscape asso](/images-wiki/f4f_gcfscape_asso.jpg) et vérifiez que tout soit cochés.

## Extraire un fichier

Double cliquez sur le fichier que vous extraire, celui-ci s'ouvrira avec GCFScape :

![f4f gcfscape extract](/images-wiki/f4f_gcfscape_extract.jpg)

![f4f gcfscape extract1](/images-wiki/f4f_gcfscape_extract1.jpg)

maintenant, choisissez où vous souhaitez extraire ces données.

L'opération est identique pour les autres extensions. A savoir que vous pouvez extraire qu'une partie en la sélectionnant.
