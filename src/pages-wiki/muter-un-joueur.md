---
title: "Muter un joueur"
---

## Description

Il peut arriver qu'un joueur utilise son micro sans arrêt avec de la musique désagréable donc au-lieu de le kicker et/ou de déconnecter, vous pouvez le muter.

## Requis

```text
* [[Avoir_la_console|Avoir la console]]
```

## Comment ?

Une fois la console ouverte, il vous suffit d'écrire :

```text
 voice_show_mute
```

![c8m5 rooftop0000](/images-wiki/c8m5_rooftop0000.jpg)
puis :

```text
 voice_mute id
```

L'id correspond au chiffre dans la colonne **Players**.

![c8m5 rooftop0001](/images-wiki/c8m5_rooftop0001.jpg)

Pour dé-muter un joueur, vous devrez écrire :

```text
 voice_unmute id
```

Et voilà, c'est terminé.
