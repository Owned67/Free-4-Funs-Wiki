## Présentation

Vote Blocker permet d'immuniser les admins et/ou le tank contre le kick par vote ainsi qu'également de configurer qui a le droit de voter, affiche un message selon le vote réalisé etc...

## Téléchargement

[Vote Blocker 1.3.1](https://tutocss.pages-perso.free.fr/wiki/l4d2_VoteBlocker.zip)

## Installation

- 1. Téléchargez l'archive
- 2. Décompressez l'archive sur votre ordinateur (avec un logiciel de décompression...)

- 3. Envoyez le contenu des dossiers **addons** et **cfg** dans le dossier **/games/l4d2/left4dead2** de votre serveur FTP

- 4. Redémarrez le serveur (Ce n'est qu'après que vous pourrez éditer le fichier de configuration **l4d2_votemanager.cfg** situé dans le répertoire **/games/l4d2/left4dead2/cfg/sourcemod/**.

**Gérer les droits de votes** :

L'auteur du plugin fournis dans son sujet, le fichier **admin_overrides.cfg**, nous l'avons inclus.

Editer le fichier de configuration **admin_overrides.cfg** situé dans le répertoire **/../../left4dead2/addons/sourcemod/configs/** :

`Overrides<br /> {<br /> 	/**<br /> 	 * By default, commands are registered with three pieces of information:<br /> 	 * 1)Command Name 		(for example, "csdm_enable")<br /> 	 * 2)Command Group Name	(for example, "CSDM")<br /> 	 * 3)Command Level		(for example, "changemap")<br /> 	 *<br /> 	 * You can override the default flags assigned to individual commands or command groups in this way.<br /> 	 * To override a group, use the "@" character before the name.
