## Présentation

Gear Transfer Permet de donner les équipements (kit de soin, adré, pipe, molo etc...) entre survivants et on peut autoriser les bots à faire de même.

## Téléchargement

[Gear Transfer](https://tutocss.pages-perso.free.fr/wiki/l4d2_gear_transfer.zip)

## Installation

- 1. Téléchargez l'archive
- 2. Décompressez l'archive sur votre ordinateur (avec un logiciel de décompression...)

- 3. Envoyez le contenu des dossiers **addons** et **cfg** dans le dossier **/games/l4d2/left4dead2** de votre serveur FTP

- 4. Redémarrez votre serveur

## Configuration
