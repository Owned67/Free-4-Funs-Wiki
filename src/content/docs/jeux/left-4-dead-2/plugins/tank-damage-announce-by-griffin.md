## Présentation

Tank Damage Announce est un plugin qui affiche les dégâts affligés par les survivants et le nombre de HP qui lui reste.

## Téléchargement

[Tank Damage Announce](https://tutocss.pages-perso.free.fr/wiki/l4d2_tank_dmage.zip)

## Installation

Comment installer le plugin ?

- 1. Téléchargez l'archive
- 2. Décompressez l'archive sur votre ordinateur (avec un logiciel de décompression...)

- 3. Envoyez le contenu du dossier addons dans le dossier **/games/l4d2/left4dead2** de votre serveur

- 4. Redémarrez le serveur

## Vérification de l'installation

- 1. Tapez la commande suivante dans la console de votre serveur (par RCON ou via le logiciel [HLSW](/divers/hlsw/)) : **sm plugins list**.
Cette commande sert à afficher la liste des plugins SourceMod installés sur votre serveur :

```text
 "Tank Damage Announce L4D2" (0.6.5d) by Griffin and Blade
```
