## Introduction

Nous allons vous expliquez les différentes variables pour pouvoir modifier votre viseur. La couleur du viseur se règle en code RVB en notation décimale.

## Configuration

cl_crosshair_alpha ![icon11](/images-wiki/icon11.gif) Permet de régler la transparence (0 - 255, plus la valeur est petite, plus le viseur sera translucide)

Les trois valeurs suivantes vous permettrons de définir la couleur, leurs valeurs sont comprises entre 0 et 255 ([Plus d'informations](http://www.toutes-les-couleurs.com/code-couleur-rvb.php))

cl_crosshair_blue ![icon11](/images-wiki/icon11.gif) Couleur bleu
cl_crosshair_green ![icon11](/images-wiki/icon11.gif) Couleur verte
cl_crosshair_red ![icon11](/images-wiki/icon11.gif) Couleur rouge

cl_crosshair_dynamic ![icon11](/images-wiki/icon11.gif) Change la taille du viseur (0 = petit, 1 = grand), à savoir que cela influe également sur la précision de vos tirs et qu'il restera fix.

cl_crosshair_tickness ![icon11](/images-wiki/icon11.gif) Change la grosseur du viseur (0 - 5).
